#### What is Markdown?

Markdown is a lightweight markup language with plain-text formatting syntax. It is designed to be easy to read and write in its raw form while providing a simple way to convert plain text into formatted HTML, PDF, or other formats. Developers and writers frequently use Markdown for documentation, README files, and taking notes because it allows formatting like headings, lists, bold text, and code blocks without requiring complex visual editors which is VS code.

#### What is Git?

Git is a distributed version control system that tracks changes made to files over time. It allows developers to record revisions, revert to previous states of a project, and collaborate with others without overwriting each other's work. Because Git is distributed, every developer has a complete local copy of the project's repository and history on their own machine, enabling offline work and fast local operations.

#### What is GitHub?

GitHub is a cloud-based hosting platform built around the Git version control system. It allows developers to store, manage, and share their Git repositories online. In addition to hosting code, GitHub provides features for project management, issue tracking, code review through pull requests, and collaborative workflows, making it a central hub for open-source projects and team development.

#### What is Slack?

Slack is a channel-based messaging platform designed for team communication and collaboration. It allows groups to organize conversations into specific public or private channels dedicated to particular topics, projects, or teams. Slack supports direct messaging, file sharing, integration with third-party tools like GitHub, and voice or video calls, serving as a unified communication tool for workplace productivity.
